# CSIRTs Network - php2shell (CVE-2026-109618 en CVE-2026-10961)
|   |   |
|---|---|
| **Date** | 21-October-2026 |
| **Number** | CNW-2026-04 | 
| **Keywords** | PHP| 
| **CVE** |  CVE-2026-109618 en CVE-2026-109619 (URL to main advisory related to event) | 
| **Details** |Two critical vulnerabilities, CVE-2026-109618 and CVE-2026-109619, have been discovered in PHP: Hypertext Preprocessor. These vulnerabilities are believed to be present in all current versions of PHP, and at the very least in all versions from 5 onwards. They allow malicious actors to perform remote code execution (RCE). The potential consequences include the takeover of (web) servers, the loss of website accessibility, data leaks, or the disruption of specific functionalities, such as the ability to log in. (source: https://advisories.ncsc.nl/)|
